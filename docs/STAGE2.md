# ЭТАП 2 — OOBE (первая настройка)

> Реализовано: «Подождите…» → регион → раскладка → учётная запись → пароль →
> «Привет» → «Мы готовим всё для вас» → итог с сохранённой учётной записью.

---

## 1. Поток

```
Reboot (логотип 5 с)
   └─▶ OobeWait         «Подождите…»                              ~3 с
        └─▶ OobeRegion   «Ваш регион?» → «Да, верно» / «Нет, выбрать другой» → список
             └─▶ OobeKeyboard   основная + вторая раскладка
                  └─▶ OobeAccount    «Кто будет использовать этот компьютер?»
                       └─▶ OobePassword   пароль + подтверждение + подсказка (или «без пароля»)
                            └─▶ OobeHello   «Привет»                 ~2.5 с
                                 └─▶ OobePreparing  «Мы готовим всё для вас»   ~9.5 с
                                      └─▶ LockScreen → (ЭТАП 3) экран-итог OOBE
```

Каждый переход по-прежнему проходит через `BootFlow`, и фаза пишется в
`state.json` **до** показа следующего экрана: закрыли на пароле — вернётесь на пароль,
и уже созданная учётная запись не потеряется.

## 3. Решения, которые стоит знать

**Пароль в открытом виде не покидает метод.** `UserAccount.SetPassword` сразу
считает PBKDF2 и сохраняет только соль, итерации и хэш. В `state.json` нет ни
самого пароля, ни подсказки в открытом виде (подсказка хранится как контрольный
ответ — так делает и Windows). Тест `PlainPassword_IsNotWrittenToStateFile`
проверяет это на реальном файле.

**PBKDF2 считается в фоне.** 600 000 итераций — это ~0.3–0.5 с на слабом ноутбуке;
хэширование идёт в `Task.Run`, поэтому кнопка «Далее» не подвешивает интерфейс, а
`CanNavigateBack` не даёт уйти с экрана во время расчёта.

**Имена проверяются по правилам Windows, а не «на глаз».** Запрещённые символы
`" / \ [ ] : ; | = , + * ? < > @`, длина 20, точка или пробел в конце, имена
`CON/PRN/AUX/NUL/COM1…/LPT1…` (включая `CON.txt`). `"..."` даёт отдельную ошибку
`AllDots` — она проверяется раньше «точки в конце», иначе пользователь получал бы
менее точное сообщение.

**Ввод не подчищается молча.** `ValidateUserName` не делает `Trim()`: пробел в
конце — это ошибка, которую видно сразу, а не незаметно исправленный ввод.

**Регион выводится из языка установки.** Выбрали русский на ЭТАПЕ 1 — OOBE
предлагает Беларусь/Россию; English — США. Это то, что делает настоящая Windows
(по IP/языку), и это видно глазом.

**Прогресс — снова `IProgress`, а не таймер.** `OobePreparer` отдаёт шаги с
процентами, экран не знает, сколько их и как они называются; отмена работает
мгновенно при выходе по `Insert`.

## 4. Чек-лист ручной проверки

1. Пройти ЭТАП 1 до перезагрузки → появляется «Подождите…» (3 с).
2. Регион: показан «Похоже, вы находитесь здесь: Беларусь» → «Нет, выбрать другой»
   → список, выбрать США → «Далее».
3. Раскладка: основная подставлена по языку; добавить вторую → сохраняется.
4. Имя: ввести `ivan` → «Далее». Проверить `CON` (зарезервировано), `ivan.`
   (точка в конце), 21 символ (слишком длинное) — ошибки показываются сразу.
5. Пароль: `123` → «не меньше 4 символов»; `abcd` / `abce` → «пароли не совпадают».
   Затем `1234` дважды → «Далее» (0.5 с на хэширование, UI не замирает).
   Отдельно проверить «Продолжить без пароля».
6. «Привет» (2.5 с) → «Мы готовим всё для вас» с этапами и прогрессом (~9.5 с).
7. Итог: имя, «пароль задан (PBKDF2-SHA256, 600 000 итераций)», регион, раскладки.
8. Открыть `%LocalAppData%\Win10Sim\state.json`: есть `Account` с `PasswordHash` и
   `PasswordSalt`, но **нет** пароля в открытом виде.
9. `Insert` на любом экране OOBE → мгновенный выход. Перезапуск → продолжаем с
   сохранённой фазы (например, с экрана пароля, с уже введённым именем).

python3 tools/check_csharp.py

CI (`.github/workflows/build.yml`) на каждый push собирает решение с `-warnaserror`,
прогоняет тесты и публикует `Win10Sim.App.exe` (автономный single-file ~60 МБ) и
framework-dependent сборку в артефакты, а на push в рабочую ветку/тег — в GitHub Release.

## 6. Что дальше (ЭТАП 3)

`LockScreen` уже существует как фаза и уже сохраняется в состоянии; вместо
`OobeCompleteView` появятся:

* экран блокировки: обои, часы, дата, поле пароля с проверкой через
  `UserAccount.CheckPassword`, «Неверный пароль» с задержкой;
* рабочий стол: обои Win10, иконки «Этот компьютер» и «Корзина» (двойной клик);
* панель задач: «Пуск», поиск, трей, часы (формат времени — из ЭТАПА 1);
* меню «Пуск»: список программ и плитки, живой поиск;
* внутренняя оконная система (`SimWindowManager`) — для Проводника и Блокнота.
