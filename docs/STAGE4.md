# ЭТАП 4 — приложения: Проводник, Блокнот, Edge, cmd, Параметры

> Реализовано: виртуальный диск `C:`, командная строка как отдельный слой ядра и
> пять приложений, которые работают с этим диском и друг с другом.

---

## 1. Виртуальный диск (`Win10Sim.Core.FileSystem`)

| Файл | Ответственность |
|---|---|
| `VfsPath` | Нормализация путей (`C:`, `/`, относительные), родитель, имя, расширение, правила имён Windows |
| `VfsNode` | Узел дерева: вид, имя, содержимое, `CreatedUtc/ModifiedUtc`, `SizeBytes` (UTF-16), глиф по расширению |
| `IVirtualFileSystem` | Контракт: `Find`, `Exists`, `CreateDirectory`, `CreateFile`, `ReadAllText`, `WriteAllText`, `Delete`, `Move`, `Copy`, `Enumerate`, `Save`, событие `Changed` |
| `VirtualFileSystem` | Реализация: дерево в памяти, `lock` на все операции, атомарная запись JSON (`vfs.json`) |
| `VfsSeeder` | Первичное дерево: `Windows\System32`, `Program Files*`, `Users\<user>\{Desktop,Documents,Downloads,Pictures,Music,Videos,AppData}`, `$Recycle.Bin`, `pagefile.sys` |

Дерево **одно на процесс**: файл, созданный `echo > note.txt` в cmd, сразу виден
в Проводнике, и наоборот. `Changed` подписывает Проводник — список обновляется
без ручного «Обновить». `FreeSpaceBytes` — константа 402 ГБ, чтобы строка
состояния выглядела как у настоящего раздела.

## 2. Командная строка (`Win10Sim.Core.Shell`)

| Файл | Ответственность |
|---|---|
| `CommandResult` | Строки вывода, `ClearScreen`, `ExitRequested`, `ExitCode`; `FromLine`, `Empty` |
| `ICommand` | `Name`, `Aliases`, `Help`, `Usage`, `ExecuteAsync(context, arguments, token)` |
| `CommandParser` | Кавычки, пробелы, редирект `>` и `>>` |
| `CommandProcessor` | Рабочая папка, история, реестр команд, Tab-дополнение, редирект результата в файл |
| `Commands/FileSystemCommands` | `dir`, `cd`, `md`, `rd`, `del`, `copy`, `move`, `ren`, `type`, `echo` |
| `Commands/SystemCommands` | `help`, `cls`, `ver`, `whoami`, `hostname`, `date`, `time`, `exit` |
| `Commands/PingCommand` | Настоящий ICMP через `System.Net.Ping`, `-n`, `-l`, `-w`, отмена по `CancellationToken` |

Баннер: `Microsoft Windows [Version 10.0.19045.5011]`. Рабочая папка по
умолчанию — `C:\Users\<user>`. Неизвестная команда отвечает как настоящий cmd:
`"фыва" не является внутренней или внешней командой…`.

## 3. Проводник (`Apps/Explorer/ExplorerView`)

* Адресная строка: путь с `Enter`, «Назад / Вперёд» (собственная история),
  «Вверх», «Обновить», «Создать папку», «Удалить».
* Слева быстрые ссылки: «Этот компьютер», рабочий стол, документы, загрузки,
  изображения, музыка, видео, корзина, «Локальный диск (C:)» — активная подсвечена.
* Список: глиф по типу, имя, дата изменения, размер; пустая папка — подпись.
* Контекстное меню: «Открыть», «Создать папку», «Создать текстовый документ»,
  «Удалить», «Переименовать» (`F2`), `Enter` — открыть, `Delete` — удалить.
* Диалог имени с проверкой правил Windows (`VfsPath.IsValidName`): пустое имя,
  `CON`/`NUL`/`COM1`, точка в конце, запрещённые символы, занятое имя.
* Двойной клик по `.txt/.log/.ini` открывает **Блокнот** с этим файлом.
* Строка состояния: «Элементов: N» и «Свободно: X из Y».

## 4. Блокнот (`Apps/Notepad/NotepadView`)

Меню «Файл / Правка / Вид» как в настоящем: создать (`Ctrl+N`), открыть
(`Ctrl+O`), сохранить (`Ctrl+S`), «Сохранить как», выход; отмена, вырезать,
копировать, вставить, выделить всё, «Время и дата» (`F5`), перенос по словам.

* Диалоги открытия и сохранения — **собственные**, работают с виртуальным диском
  (системные `OpenFileDialog` трогали бы реальный диск пользователя).
* Автосохранение: если у документа есть путь, текст пишется через 1.5 с после
  последней правки; кнопка «Сохранить» делает это сразу.
* Строка состояния: «Строка N, столбец M» и путь к файлу.
* Заголовок окна меняется на «<файл> — Блокнот» через `ISimWindowAware`.

## 5. Microsoft Edge (`Apps/Edge/EdgeView`)

Настоящий Chromium — `Microsoft.Web.WebView2` (пакет зафиксирован на 1.0.2903.40).
Адресная строка ведёт себя как в Edge: `example.com` → `https://example.com`,
фраза без точки → поиск Bing, `https://…` → как есть. Назад / Вперёд /
Обновить / Новая вкладка, индикатор загрузки.

* Профиль (`cookies`, кэш) — в `%LocalAppData%\Win10Sim\WebView2`; профиль и
  реестр настоящего Edge не трогаются.
* Если **WebView2 Runtime не установлен**, вместо падения показывается
  объяснение с типом ошибки — симулятор продолжает работать.
* При закрытии окна движок освобождается (`Dispose`), чтобы не оставался
  процесс `msedgewebview2.exe`.
* Сборка `self-contained` включает библиотеки WebView2, но сам **Runtime**
  ставится отдельно (он есть в Windows 11 и в обновлённой Windows 10).

## 6. Командная строка (`Apps/Cmd/CmdView`)

Чёрное окно, баннер, история (`↑`/`↓`), `Tab` — дополнение команд и имён файлов,
`Ctrl+C` — прерывание (например, `ping -t`), `cls` очищает экран, `exit`
закрывает окно, а не приложение. Команды исполняет `CommandProcessor` из ядра —
окно только печатает `CommandResult`.

## 7. Параметры (`Apps/Settings/SettingsView`)

Разделы: «Система» (имя устройства, виртуальный диск), «Персонализация» (тема,
формат часов), «Время и язык» (ru/en — переключает словари на лету),
«Учётные записи» (пользователь, задан ли пароль), «О системе» (выпуск, версия
10.0.19045, процессор, память). Изменения сразу пишутся в `desktop.json`.

## 8. Тесты

Добавлено 30 тестов (`VirtualFileSystemTests`, `CommandProcessorTests`):
сидер, регистронезависимость, создание/удаление/копирование/переименование,
правила имён, сохранение и загрузка JSON, `dir`/`cd`/`md`/`echo >`/`>>`/`type`/
`copy`/`ren`/`del`/`cls`/`exit`/`help`/`whoami`, история, `Tab`-дополнение,
разбор кавычек и редиректа.

## 9. Чек-лист ручной проверки

1. «Пуск» → Проводник: слева ссылки, в `C:\` папки `Windows`, `Program Files`, `Users`.
2. Создать папку, переименовать (`F2`), удалить (`Delete`), «Назад»/«Вперёд» работают.
3. Двойной клик по `C:\Users\<user>\Documents\Заметки.txt` → Блокнот с текстом.
4. В Блокноте дописать строку → закрыть окно → открыть файл снова: текст на месте.
5. «Пуск» → Командная строка: `dir`, `cd ..`, `md тест`, `echo привет > a.txt`,
   `type a.txt`, `help`, `exit`.
6. Проводник показывает `a.txt`, созданный в cmd.
7. «Пуск» → Microsoft Edge: открывается страница; без WebView2 Runtime —
   понятное сообщение вместо падения.
8. «Пуск» → Параметры: переключить формат часов → часы в трее меняются.
9. Окна: свернуть в панель задач, развернуть двойным кликом по заголовку,
   перетащить, изменить размер, закрыть.
10. `Insert` — выход на реальный рабочий стол в любой момент.
