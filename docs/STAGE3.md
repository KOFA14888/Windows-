# ЭТАП 3 — рабочий стол Windows 10

> Реализовано: экран блокировки → вход по паролю → рабочий стол с обоями,
> иконками, панелью задач, меню «Пуск», центром уведомлений и питанием.

---

## 1. Поток

```
OobePreparing «Мы готовим всё для вас»
   └─▶ LockScreen    часы, дата, «нажмите любую клавишу» → вход по паролю
        └─▶ Desktop  обои, иконки, панель задач, «Пуск», уведомления
             ├─ «Пуск» → Питание → Перезагрузка  → оверлей 2.5 с → LockScreen
             ├─ «Пуск» → Питание → Сон           → чёрный экран → клик → LockScreen
             ├─ «Пуск» → Питание → Выход/Блокировка → LockScreen
             └─ «Пуск» → любое приложение        → окно на рабочем столе (ЭТАП 4)
```

`OsPhase.LockScreen = 18`, `OsPhase.Desktop = 19`; обе фазы обслуживает
`BootFlow` (раньше `LockScreen` показывал итог OOBE). Выход из симулятора —
по-прежнему **только `Insert`**, глобальный хук в `Platform/InsertKeyHook.cs`
перехватывает клавишу до того, как её увидит оболочка.

## 2. Экран блокировки (`Screens/Shell/LockScreenView`)

| Элемент | Поведение |
|---|---|
| Обои | `Assets/Wallpaper.jpg` с `BlurEffect` 22 px — как размытие акрила в Windows |
| Часы и дата | Обновляются раз в секунду, формат из `CultureInfo.CurrentCulture` («суббота, 30 октября») |
| «Нажмите любую клавишу» | Любой клик или клавиша открывает панель входа; `Esc` возвращает «обложку» |
| Панель входа | Аватар с инициалом, имя, `PasswordBox`, кнопка со стрелкой, `Enter` |
| Неверный пароль | Красный текст + «тряска» панели (6 затухающих смещений), поле очищается |
| Нет пароля | Кнопка «Войти без пароля» — как в Windows с пустым паролем |
| Подсказка | Показывается контрольный вопрос из OOBE (ответ не раскрывается) |
| Успешный вход | «Добро пожаловать, <имя>» 0.9 с → `Advance(OsPhase.Desktop)` |

Пароль проверяется тем же `UserAccount.CheckPassword` (PBKDF2-SHA256, 600 000
итераций) — симулятор не хранит и не сравнивает открытый пароль.

## 3. Рабочий стол (`Screens/Shell/DesktopView`)

### Обои и иконки

`Wallpaper.jpg` (1920×1080, сгенерированные обои: тёмно-синий фон и светящееся
окно — «ночной город»), иконки «Этот компьютер» и «Корзина». Двойной клик
открывает Проводник на `C:\` или на `C:\$Recycle.Bin` (двойной клик
определяется по времени и цели — у `Border` нет `ClickCount`).

Контекстное меню пустого места: «Создать» → папка/текстовый документ (создаётся
настоящий узел VFS в `C:\Users\<user>\Desktop`), «Обновить», «Персонализация»,
«Параметры экрана». Меню не открывается по клику внутри окна приложения —
проверяется `e.OriginalSource`.

### Панель задач (`TaskbarView`)

Слева — «Пуск», поиск, «Просмотр задач»; в центре — кнопки открытых окон
(активное подсвечено, повторный клик сворачивает); справа — язык (РУС/ENG),
сеть, звук, часы и дата, «Показать рабочий стол» (свернуть все окна) и
индикатор уведомлений. Часы берут формат из `DesktopSettings.ClockFormat`
(`HH:mm` или `h:mm`).

### Меню «Пуск» (`StartMenuView`)

Список приложений с поиском (`Tab`/`Enter` — обычная навигация), плитки
закреплённых приложений (цвет и глиф из `AppCatalog`), кнопка пользователя,
ссылка «Параметры» и меню питания: «Завершение работы», «Перезагрузка», «Сон»,
«Выход», «Блокировка».

Питание:

* **Завершение работы** — честное уведомление: реального выключения в симуляторе нет.
* **Перезагрузка** — оверлей «Перезагрузка…» 2.5 с → `LockScreen`.
* **Сон** — чёрный экран, «будит» любой клик (или 12 с), затем `LockScreen`.
* **Выход / Блокировка** — сразу `LockScreen`, окна приложений остаются в памяти.

### Центр уведомлений

Быстрые действия (Wi-Fi, Bluetooth, режим «в самолёте», ночной свет) с
состоянием в `Tag` кнопки (стиль `Button.QuickAction` реагирует на `on`/`off`),
плитки «Все параметры» и «Не беспокоить», лента уведомлений. Уведомления
(toasts) всплывают справа снизу и живут 6 секунд; при первом запуске
показывается подсказка про выход по `Insert`.

## 4. Внутренние окна (`Shell/SimWindow`, `Shell/SimWindowManager`)

Окна приложений — это не HWND, а контролы `SimWindow` на общем `Canvas`.
Так панель задач и «Пуск» всегда выше любого окна без `Topmost` и без
переключения фокуса реальной Windows.

| Возможность | Реализация |
|---|---|
| Заголовок | 32 px: глиф приложения, название, «свернуть / развернуть / закрыть» |
| Перетаскивание | За заголовок, координаты ограничены рабочей областью |
| Размер | Уголок справа снизу (`Rectangle`, `Cursor=SizeNWSE`), минимум 380×240 |
| Развернуть | Двойной клик по заголовку или кнопка; запоминаются прежние границы |
| Свернуть | Окно скрыто, но живёт: состояние приложения не теряется |
| Z-order | `Panel.ZIndex` с монотонным счётчиком, активно ровно одно окно |
| Одно окно на приложение | `SimWindowManager.Open(appId, factory, singleInstance: true)` |
| Рабочая область | `UpdateWorkArea` при `SizeChanged` оболочки; окна «прилипают» внутрь |

`SimWindowManager.Attach(Canvas)` / `Detach()` — оболочка при перезагрузке
создаётся заново, а окна приложений остаются в памяти менеджера.

## 5. Персонализация (`Infrastructure/DesktopSettings`)

`%LocalAppData%\Win10Sim\desktop.json`: `Theme`, `ClockFormat`, `AccentColor`
(`#0078D7`), `Wallpaper`, `FirstRunTipsShown`. Файл отдельный от `state.json`:
сброс установки не должен сбрасывать оформление.

## 6. Новые строки и стили

`Themes/Lang.ru.xaml` / `Lang.en.xaml` — около 90 ключей `L.Shell.*`, `L.Lock.*`,
`L.Toast.*`, `L.Hint.Insert`. `Themes/Styles.xaml` — `Button.Tray`,
`Button.TaskbarApp`, `Button.QuickAction`, `MenuItem.Sim`, `ContextMenu.Sim`,
`Button.NavIcon`, `Button.Sidebar`.

## 7. Чек-лист ручной проверки

1. Дойти до конца OOBE → экран блокировки: часы идут, дата по-русски.
2. Клик → панель входа → неверный пароль → «тряска» и сообщение; верный → рабочий стол.
3. Обои на весь экран, иконки «Этот компьютер» и «Корзина», панель задач снизу.
4. Двойной клик по «Этот компьютер» → Проводник на `C:\`.
5. «Пуск» → плитки приложений, поиск фильтрует список.
6. Питание → «Перезагрузка» → оверлей → экран блокировки.
7. Питание → «Сон» → чёрный экран → клик → экран блокировки.
8. Клик по пустому месту → контекстное меню → «Создать» → папка → она видна в
   Проводнике на рабочем столе.
9. `Esc` закрывает «Пуск» и центр уведомлений.
10. `Insert` в любой момент — выход на реальный рабочий стол.
