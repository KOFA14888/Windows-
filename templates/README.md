# Шаблоны «Fullscreen + Insert»

Три минимальных проекта, реализующих **критические требования** из постановки:
безрамочное окно на весь экран и выход строго по `Insert`. Тяжёлая часть (экраны
установки, оболочка) сюда намеренно не входит — это ЭТАП 1+.

| Папка | Стек | Как собрать |
|---|---|---|
| `csharp-wpf/` | .NET 8, WPF (**эталон**) | `dotnet run` |
| `csharp-winforms/` | .NET 8, WinForms | `dotnet run` |
| `cpp-sfml/` | C++17, SFML 2.6 | см. комментарий в начале `main.cpp` |

Все три запускаются только на Windows.

## Что важно в шаблоне WPF

1. **`ShutdownMode="OnExplicitShutdown"`** (`App.xaml`) — приложение не может
   закрыться из-за закрытия окна. Только `App.RequestExit()`.
2. **Хук ставится до создания окна** (`App.OnStartup`) — перехват работает
   от первого кадра, а если UI упадёт на инициализации, `DispatcherUnhandledException`
   вызовет `RequestExit()`.
3. **`Fullscreen.Apply()`** снимает у HWND `WS_CAPTION | WS_THICKFRAME | WS_SYSMENU |
   WS_MINIMIZEBOX | WS_MAXIMIZEBOX` и растягивает окно на `rcMonitor`. Итог: нет
   заголовка, нет Alt+Space, нет кнопок «свернуть/развернуть/закрыть» — окно
   неотличимо от полноэкранного.
4. **`InsertKeyHook`** (WH_KEYBOARD_LL) ловит `Insert` глобально и «съедает» его
   (`return 1`), чтобы клавиша не утекла в другое приложение. Делегат хранится
   в поле — иначе GC соберёт его и хук упадёт на первом нажатии.
5. **`PreviewKeyDown`** — резервный путь, если хук не установился (политики,
   античит, wow64).
6. **`TaskbarVisibility`** — опционально. По умолчанию не вызывается: topmost-окно
   и так закрывает панель задач, и это безопаснее (при убийстве процесса панель
   остаётся на месте). Для полного киоска — `TaskbarVisibility.Hide()`, но помните:
   при `End task` панель задач исчезнет до перезапуска `explorer.exe`.

## Почему exclusive fullscreen не используется

WPF/WinForms/SFML-окно не может занять «монопольный» видеорежим так, как это делает
DXGI-игра. Визуально разница отсутствует, а borderless-подход не вызывает чёрных
миганий при Ctrl+Alt+Del и Alt+Tab. Для симулятора интерфейса это единственно верный выбор.
